# AI-воркшоп: оркестратор

Воркшоп, где команды из трех человек с ИИ-агентами (Claude Code или Codex)
достраивают банк из трех сервисов, а симулятор клиентов на общем табло
показывает, как каждая правка меняет клиентскую базу.

Здесь симулятор с табло, шаблон репозитория команды, скрипты сетапа и
документация организатора.

| Что | Где |
|---|---|
| развернуть воркшоп, инструкция для агента | [SETUP.md](SETUP.md) |
| провести день воркшопа | [RUNBOOK.md](RUNBOOK.md) |
| как все устроено | [ORGANIZER.md](ORGANIZER.md) |
| что получает команда | [team-template/](team-template/) |

Быстрый старт: открой репозиторий в Claude Code или Codex и попроси
развернуть воркшоп по `SETUP.md`.
