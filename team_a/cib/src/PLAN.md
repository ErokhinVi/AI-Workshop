# План стыковки CIB

## Цель

Согласовать, какие ручки и данные нужны между backend, cib и retail для кредитной функции.

## Договорённости

- backend отдаёт данные клиента по `GET /clients/{client_id}`.
- cib принимает заявку на решение по `POST /credit/decide`.
- retail отправляет заявку клиента в cib и показывает клиенту решение.

## Следующие шаги

- Уточнить формат заявки на кредит.
- Уточнить формат ответа по решению.
- После согласования обновить этот план через `POST /meta/plan`.
