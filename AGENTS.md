# AGENTS.md: оркестратор AI-воркшопа (Codex)

Codex читает этот файл автоматически. Полные правила в `CLAUDE.md`: прочитай
его целиком и работай по нему. Коротко:

- развернуть воркшоп: `SETUP.md`;
- провести день воркшопа: `RUNBOOK.md`;
- устройство и правила оценки: `ORGANIZER.md`.

Скриптам `tools/setup` нужна сеть (gh, curl, api.github.com). Если песочница
Codex ее режет, попроси человека разрешить сеть для этих команд.

Секреты не печатать и не коммитить. Аккаунты, оплату и ключи делает человек.
